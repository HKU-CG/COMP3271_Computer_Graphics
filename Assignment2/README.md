## Shader interface and conventions

Use GLSL `#version 330 core` and keep the supplied interface declarations.

| Attribute location | Type | Meaning |
| --- | --- | --- |
| 0 | `vec3 a_position` | Object-space position |
| 1 | `vec3 a_normal` | Object-space geometric normal |
| 2 | `vec2 a_uv` | UV coordinate for the texture shader |

`u_model`, `u_view`, and `u_projection` are column-vector transformation matrices.
Use world space for lighting positions, directions, and normals. `u_light_pos`
and `u_camera_pos` are world-space positions. `u_base_color`, `u_shininess`, and
`u_uv_scale` control material color, the specular exponent, and UV repetition.
The framework binds `u_texture` to texture unit 0.

The bunny's UVs are generated by spherical mapping. Some stretching and a visible
seam are expected; use the Detail plane for clean texture checks. Mesh normals,
UV generation, texture filtering, and mipmap generation are provided.

## Part 1 — Coordinates and geometric normals (20 marks)

In `normal.vert`, transform the position through model, view, and projection, and
pass the world-space geometric normal to the fragment shader. Use the normal
matrix `mat3(transpose(inverse(u_model)))`, which handles nonuniform scaling, and
normalize the transformed vertex normal before passing it on.

In `normal.frag`, normalize the interpolated normal and map its signed components
from `[-1,1]` to RGB `[0,1]`. Output alpha 1.

**Check:** rotating the model changes its normal colors; moving the light does
not. The normal directions remain correct with **Nonuniform scale** enabled.

## Part 2 — Blinn–Phong lighting (50 marks)

In `blinn_phong.vert`, pass world-space position and correctly transformed normal
to the fragment shader. In `blinn_phong.frag`, implement ambient, Lambert diffuse,
and Blinn–Phong specular lighting. Normalize N, L, and V, and form the halfway
vector H from L and V. Clamp dot products before using them. When N·L <= 0, the
specular term is zero.

Use the following common material model for Parts 2 and 3:

- ambient: `0.15 * diffuse_color`;
- diffuse: `0.75 * diffuse_color * max(dot(N, L), 0)`;
- specular: white, coefficient `0.55`, exponent `u_shininess`.

For Part 2, `diffuse_color` is `u_base_color`.

**Check:** moving the light changes diffuse shading; moving the camera changes
specular highlights. Increasing shininess produces a narrower highlight. Backlit
surfaces retain ambient light without a specular highlight.

## Part 3 — Texture mapping with lighting (30 marks)

In `texture.vert`, pass world-space position, correctly transformed normal, and UV
scaled by `u_uv_scale`. In `texture.frag`, sample `u_texture` and use its RGB
multiplied by `u_base_color` as `diffuse_color` in the same lighting model as Part 2.
The specular color remains white; do not multiply it by the color texture.

**Check:** increasing UV scale repeats the pattern without changing the geometry.
The supplied **Filtering** control selects nearest, bilinear, or trilinear mipmap
sampling. Inspect the Detail plane at an oblique angle and different distances.
The framework provides the sampling modes; implementing filters is not assessed.

## Bonus — Shadow visibility (+5 marks, optional)

Edit only the marked `shadow_visibility` function in `shadow.frag`. The supplied
vertex shader passes `v_light_clip`; the framework renders a 2048 × 2048 depth map
using the supplied `shadow_depth.vert/.frag`. The bonus uses one directional light
and texture unit 2 for `u_shadow_map`.

Return visibility 1 for a lit fragment and 0 for a shadowed fragment:

1. Divide light clip xyz by w and remap from `[-1,1]` to `[0,1]`.
2. Treat coordinates outside the light frustum, or w <= 0, as visible.
3. Sample the stored depth and compare it with the fragment's projected depth,
   subtracting `u_shadow_bias` from the latter before comparison.

The supplied lighting applies visibility to diffuse and specular light and keeps
ambient light. Hard shadows are sufficient for all five bonus marks.

**Check:** open the bonus tab and use **Frame shadow scene** in the bonus controls
for a clear ground-plane view. **Apply shadow** changes the bunny's cast shadow on
its ground plane. Changing light yaw/elevation moves the shadow; the **Depth bias**
control lets you inspect self-shadow artifacts and excessive shadow separation.
The bonus is independent of the three required parts.
